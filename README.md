# proyecto_voto_2026
Sistema web de votación escolar para el Municipio Escolar 2026. Los alumnos votan desde el celular con su DNI, un solo voto y en secreto, con cédula adaptada a su nivel. El panel permite gestionar padrón, candidatos y mesas, ver reportes en vivo, anular votos con motivo e imprimir actas. Hecho en PHP y MySQL.
